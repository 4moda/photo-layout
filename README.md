# PhotoLayout

X / Instagram への写真投稿を準備するための iOS アプリ（開発中）。

写真家のワークフロー「撮影 → レタッチ（Lightroom等） → 書き出し → SNS投稿」の最後の区間を高速化する。レタッチはしない。**トリミング・枠付け・配置**と、**プラットフォーム仕様に正確な高解像度書き出し**だけをやる。

- X の枚数別タイムライン表示（1〜4枚）に合わせたクロッププレビューと個別JPEG書き出し
- Instagram の 1:1 / 4:5 / 1.91:1、コラージュ、カルーセル（写真がページをまたぐシームレス配置対応）
- プレビューと書き出し結果が構造的に一致するレンダリング設計
- 元画像の実解像度ベースの書き出し（長辺4096px）
- ランタイム通信ゼロ・すべてオンデバイス

## 開発

このリポジトリは Mac を持たない環境（WSL2 + GitHub Actions）で開発されている。詳細は [CLAUDE.md](CLAUDE.md) を参照。
